# Kuku

A ten-question mental arithmetic drill: addition, subtraction, multiplication and
division, against a clock you set (5, 10, 20 or 30 seconds per question).

Three difficulty levels, four operations you can switch on and off, skip and
end-round controls, a per-player run log and a progress chart. Everything runs in
the browser; records are kept in the browser's own storage, per player name, on
that device.

Open it, then on iPhone use **Share > Add to Home Screen** to install it as an
offline app.

Named for 九九, the multiplication-table chant.
